## 用

- GitHub 在不想下载完整项目时，快速下载指定项目内单一文件夹
  - 利用浏览器本地 cache + http 后台浏览，把浏览器 cache 转成文件并打包
  - https://download-directory.github.io/
- 微舆：创新型 多智能体 舆情分析系统
  - 出门装需要至少 3 个服务 Api （TAVILY_API_KEY 、BochaAPI 或 AnspireAPI、LLM API），其中如果 LLM 只有一个的情况下，输出的结果其实价值不大。
  - 本质是通过多个 LLM（openai、千问、deepseek、Gemini 、Kimi ）执行相近且固定的 prompt 去获取答复 ，然后放到一个主持人（还是一个 LLM）进行二次讨论，将过程和讨论结果在固定的 prompt 下（又一个 LLM）去输出报告。当 问题收集、主持人讨论、报告输出 都用相同 LLM 的时候，它就开始自娱自乐。
  - https://github.com/666ghj/BettaFish
