260420 - 寤寐不宁

寤：醒时；寐：睡时；寤寐：日夜。日夜都不得安宁，形容十分惊慌与焦虑

跑

  • 跑步：每周 70km ，完成 72KM + 49KM
  • 俯卧撑：7 x 20 个 ，完全中断

学

  • 惯用手是习惯用左手或者右手，没想到还有惯用眼测试；以及鼻子的两个鼻孔也不是同时工作
  • 持续学习却不爱“输出”，这是为什么？输入是你在挑选别人，而输出是你在被别人挑选；输出决定了下限，输入决定你的上限；输出是你在完成自己的一部分自我，把混乱的自我梳理清楚，把自己还给自己
  • 一位母亲的成就，能很大程度上影响孩子的认知。一位父亲能达到的成就，在某种程度上决定了子孙后代的高度。不仅仅是家庭教育问题，更是社会学问题
  • 嫉妒并非单一情绪，而是三种情绪的复合体：渴望是起点，自卑是催化剂，怨恨才是最终的外显行为；知道自己是谁、在走向哪里、为什么做当下的选择——当这个内核足够稳固的时候，外界的嫉妒也好、赞美也好，都只是噪音
  • 红皇后效应：你必须不停奔跑，才能留在原地。你不练，别人练，你就出局；你练了，大家都练，一起卷；个体理性，导致集体困境
  • 知识必定是结构化的，而不是零碎的时间、阅读零碎的文档；一本书之所以有价值，就是前因、验证、结论都完整的放在一起
  • 人们，会拿着自己的金钱和时间去换另外一群人创造的产品，通过相互交易获取复利进步
  • 猫还是独居动物。狗是群居的，嚎叫能唤来同伴保护，表达痛苦有进化收益。猫没有这种社会结构，叫了不会有同类来帮忙，反而可能招来竞争者抢地盘。自然选择的结果很直接：猫进化出了一套极其高效的疼痛行为压制策略，不是不痛，是不能让别的动物知道自己痛
  • 语义磨损带来的最大问题，并不是表达减少，而是表达变粗、高亮、扎眼
  • 假装快乐，并在每件事中寻找积极的一面，你的视角就会改变；开始寻找积极的一面，而不是沉溺于消极情绪

花

  • 爆弹 爆弾 (2025)
    • 推荐指数 7/10
    • 看完之后十分恍惚，无法判断正反派角色的设定。失去对人设的焦点，忘却对实体化的凝视，仿佛看了一个视频侦探小说。可惜尾部阶段结束太快，貌似在答案立即爆炸的情况下不加速也会变得无聊

阅

  • https://www.allthingsdistributed.com/2026/04/s3-files-and-the-changing-face-of-s3.html
    • AWS 基于 S3 storage 构建了多种性能的对象存储、S3 tables（iceberg 商业版）、S3 files（类似 NFS 网络存储能力)、S3 vector（向量存储检索）等能力，文档描述 S3 这些年的发展、市场对 S3 存储需求以及对应的实现
  • 《DySkew: Dynamic Data Redistribution for Skew-Resilient Snowpark UDF Execution》
    • https://arxiv.org/abs/2604.13034
    • Snowflake 团队发现 UDF 函数在数据倾斜场景下性能非常差，通过数据感知、转换与加工实现性能的提升，降低查询长尾效应。
  • 《BERT: Pre-training of Deep Bidirectional Transformers for Language Understanding》
    • https://arxiv.org/html/1810.04805
    • Google 团队出的 BERT （深度双向 Transformer 的预训练），相比 GPT （单向 Transformer 训练）提升训练主体左右 context 信息，进一步加强问答和语言推理的准确性
    • 更多解释可以围观该论文的 Trackbacks
