学

  • 过了腊八就是年，北方进入半过年的状态（实际毫无任何气氛）；为过年气氛+1 去买个腊八粥，发现溢价严重；
    • 以前的过年是期盼着消费，期盼着穿新衣、吃好饭；现在的过年是一场又一场的智商大决战，用引导、金银堆砌的信仰景观，有着五彩琉璃挂金衣
  • 门槛低 + 装备贵 + 社交属性强 = 「体育三大毒」；比如 跑步、骑行、羽毛球，从入门到社交一气呵成，从社交转半职业遥遥无期
  • 有 Ai 之前，大家按照职能互相配合工作，有些拖延也算是将过且过；有 Ai 之后，人人都是「万能状态」，结果是 BUG 在那里光看不修；Ai 让每个人都去做自己了，人在组织内，心在发财梦

  • 有两样无形之物，人人生而平等，但多数人的大部分配额都在不自觉中被浪费：一为时间，二为情绪；时间的浪费使其缺少方向感，情绪的浪费使其缺乏足够心力，两者兼具，停留在低维度重复或内耗，再难破局。

  • 冷知识：云闪付 APP 可以查个人名下所有银行卡；人行个人征信可以查个人名下所有贷款；中国结算 APP 可以查个人名下所有持仓股票、债券以及场内基金等；基金 E 账户 APP 可以查个人名下所有持仓场外基金；金事通 APP 可以查个人名下所有的保险。

用

  • GitHub 在不想下载完整项目时，快速下载指定项目内单一文件夹
    • 利用浏览器本地 cache + http 后台浏览，把浏览器 cache 转成文件并打包
    • https://download-directory.github.io/
  • 微舆：创新型 多智能体 舆情分析系统
    • 出门装需要至少 3 个服务 Api （TAVILY_API_KEY 、BochaAPI 或 AnspireAPI、LLM API），其中如果 LLM 只有一个的情况下，输出的结果其实价值不大。
    • 本质是通过多个 LLM（openai、千问、deepseek、Gemini 、Kimi ）执行相近且固定的 prompt 去获取答复 ，然后放到一个主持人（还是一个 LLM）进行二次讨论，将过程和讨论结果在固定的 prompt 下（又一个 LLM）去输出报告。当 问题收集、主持人讨论、报告输出 都用相同 LLM 的时候，它就开始自娱自乐。
    • https://github.com/666ghj/BettaFish
